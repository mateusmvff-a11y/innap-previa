# INNAP · prévia do site

Prévia estática para aprovação do cliente. Site em HTML, CSS e JavaScript,
sem build e sem dependências de servidor.

- 20 telas, começando por `index.html`
- `mapa.html` lista todas as telas
- `home.css` e `paginas.css` são as folhas; `cromo.js` e `home.js`, o comportamento

Conteúdo baseado no protótipo INNAP v0.12.

**Pendente de confirmação antes de publicar de verdade:** a atribuição das
fotos dos professores e as datas das próximas turmas. Enquanto isso, as
páginas levam selo de prévia e `noindex`.
