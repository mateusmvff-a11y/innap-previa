# INNAP · prévia do site

Prévia estática para aprovação do cliente. HTML, CSS e JavaScript,
sem build e sem dependências de servidor.

- 34 telas, começando por `index.html`
- `mapa.html` lista todas
- `home.css` e `paginas.css` são as folhas; `cromo.js` e `home.js`, o comportamento

Conteúdo baseado no protótipo INNAP v0.12.

**Pendente de confirmação:** a atribuição das fotos dos professores e as
datas das próximas turmas. Enquanto isso, as páginas levam selo de prévia
e `noindex`.
